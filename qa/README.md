# Repositorio QA - CeluAccel

Este directorio contiene la documentación y gestión de Calidad (QA) para el proyecto CeluAccel. A continuación se describe la estructura de carpetas y su propósito:

## Estructura del Directorio

- **01_Plan_Maestro_Pruebas:**
  Almacena el documento rector de la estrategia de pruebas, donde se definen el alcance, los recursos, el cronograma y los tipos de pruebas que se aplicarán a lo largo del trimestre.

- **02_Casos_de_Prueba:**
  Contiene todos los escenarios y casos de prueba detallados (asociados a las Historias de Usuario y Casos de Uso), especificando los pasos, datos de entrada y resultados esperados.

- **03_Matriz_Trazabilidad:**
  Guarda la matriz que relaciona los requisitos del sistema con los casos de prueba, garantizando que el 100% de las funcionalidades del software estén cubiertas y verificadas.

- **04_Registro_Bugs:**
  Centraliza los reportes, historiales y seguimientos de las incidencias o defectos encontrados durante las ejecuciones de prueba, detallando su severidad y estado de corrección.

- **05_Evidencias:**
  Sirve como repositorio de las capturas de pantalla, videos, registros (logs) y salidas generadas durante la ejecución de las pruebas que respaldan los resultados obtenidos.

- **06_Informes:**
  Aloja los reportes parciales y el informe final de calidad consolidado, reflejando el estado del software, la cantidad de defectos detectados y los porcentajes de éxito.

- **07_Metricas:**
  Registra los indicadores de rendimiento y calidad del proceso de pruebas (como densidad de defectos, eficacia de detección y cobertura de pruebas).

- **08_Presentaciones:**
  Almacena el material visual y las diapositivas utilizadas para las sustentaciones y entregas de resultados ante el instructor y el equipo.
